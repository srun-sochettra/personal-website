# Contributing

Keep changes focused on this React/Vite portfolio. Preserve its distinction from other portfolio repositories and avoid treating historical project copy as verified current facts.

## Before changing content

Review exact repository names in projects.config.js, demo destinations, profile copy and contact configuration. Do not invent project metrics, release status, employment history or screenshots. Populate Markdown posts deliberately rather than relying on registry fallback titles/dates.

## Verification

Run the existing lint/build scripts and report actual commands and results. No automated suite is supplied. A successful build would not verify GitHub availability, Supabase policies, Formspree delivery or accessibility.

Check case-sensitive imports, direct route reloads, repository rename joins, failed API requests, missing configuration and relative README images. Use synthetic guestbook messages and a controlled contact destination. For UI changes, check keyboard navigation, focus restoration, narrow layouts, large text, reduced motion and loading/error/empty states.

Add focused regression checks for non-trivial logic changes without introducing a framework solely for a small edit. Keep generated builds, private configuration and unrelated refactors out of commits.

## Pull requests

Explain the problem, focused change, checks actually performed, integration impact and remaining gaps. Follow SECURITY.md for sensitive reports. No contribution implies a response-time commitment.
